MCP Semantic Tool Routing Benchmark

Can one orchestrator tool route a request to the right capability without loading every MCP tool schema into the model's context?

Code & data on GitHub Download dataset v1.0.0 (CSV, 122 KB zip)
101semantic operations

505hand-authored queries
606indexed examples
24compound requests

This page accompanies the paper Scalable Semantic Routing and QoS-Aware Provider Selection for MCP Agents (Mishra, Panditrao, Parab, Sharma, Mishra, Saha; ICMLDE 2026, Procedia Computer Science). The repository contains the registry, the 505 labelled queries, the cached gemini-embedding-001 vectors, saved outputs of every model run, and the scripts behind each table, so the retrieval results reproduce offline without any API key.

Top-3 recall of flat dense retrieval is 99.60%. Hard hierarchical gating makes the correct operation unreachable for 51 of 505 queries. For 23 of 24 compound requests a single embedding places every constituent operation in its top 10. These are operation-routing results, not end-to-end task success.

Quick start

git clone https://github.com/amrittmishra/mcp-semantic-tool-routing-benchmark
cd mcp-semantic-tool-routing-benchmark
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export PYTHONPATH=.
python -m benchmark.hierarchy_experiment        # Tables 1–2, offline
python -m benchmark.research.lexical_hybrid     # Table 5 lexical/hybrid rows, offline
python -m benchmark.research.tune_blend         # multi-vector cross-validation, offline

Dataset files

FileRowsDescription
servers.csv18One row per downstream synthetic MCP server
tools.csv101One row per semantic operation, with taxonomy class/type and description
queries.csv505Hand-authored routing queries with gold operation, tool and server labels
tool_examples.csv606Positive and negative example phrasings used in the indexed documents
tool_parameters.csv160Flattened input schemas

The queries were written by the authors after the registry was fixed; two coincide with a positive example up to capitalisation and one differs by a single word, and all three are routed correctly by every method. The catalogue is synthetic and English-only; see the dataset card in the repository for intended uses and limitations.
